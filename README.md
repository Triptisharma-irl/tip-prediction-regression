# Tip Prediction (Regression)

A regression project predicting restaurant tip amount using Linear Regression.

## Overview
Built a model to predict tip amount based on total bill, group size, and other factors using the classic Tips dataset.

## Tech Stack
Python, Pandas, Scikit-learn

## Results
- Mean Absolute Error: 0.67
- R² Score: 0.44

## Key Insight
Group size was the strongest predictor of tip amount, even more than total bill.
